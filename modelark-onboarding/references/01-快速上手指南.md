# ModelArk 快速上手指南：由 AI Agent 执行

版本：review draft v2 · 核验日期：2026-10-21 至 2026-10-22 · 适用范围：BytePlus ModelArk

本指南用于让 Agent 完成账户准备、模型激活、API 调用、私有素材库和真人能力的开通与验证。用户只提供无法自行发现的业务选择，并配合敏感步骤。本次交付为文档草稿，尚未执行账户开通或付费测试。

详细操作见 [ModelArk Onboarding Guide](02-ModelArk-Onboarding-Guide.md)；未决问题、官方来源和检查结果见 [待确认与核验记录](03-待确认与核验记录.md)。两份指南共用 `MA-00` 至 `MA-12` 步骤 ID。

## 1. 把任务交给 Agent

可直接发送以下任务描述，并补充已知信息：

> 按本指南检查并完成指定 BytePlus 账户的全部目标能力：基础生成、API、虚拟肖像私有素材和真人参考生成。先检查已有资源，再补齐缺项。自行读取可访问的状态和配置；只向我询问无法发现的业务信息。合同、购买、身份认证、真人授权、凭据及安全配置变更按交接表处理。保留默认安全配置。每项能力分别验收，遇到资格或商务限制时保留进度，继续不依赖该阻塞的工作。不要把部分完成报告成全部完成。

### 启动时需要的信息

| 信息 | Agent 先做什么 | 何时需要用户补充 |
|---|---|---|
| 账户、组织、区域、项目 | 读取现有登录态和选中配置，仅记录必要标识 | 有多个候选或无法确认目标时 |
| 目标模型及版本 | 默认激活下列八个模型，Agent 查询并记录实际模型 ID | 不询问模型清单；不可用的模型逐项报告，不静默替换 |
| 能力范围 | 本指南默认覆盖全部四类能力 | 要缩减范围时明确记录，不自行跳过真人能力 |
| 商务权益 | 检查已生效的合同、权益和订单状态 | 协议未写明或尚待商务开通时 |
| 采购与计费 | 激活采用 Seedance 2.5 资源包，币种 USD；后续按实际适用抵扣及 pay-as-you-go 计费 | 不询问测试预算、次数、是否允许按量计费或续费；敏感采购仍交用户核对具体订单并支付 |
| 素材 | 检查可访问素材的格式、尺寸、时长 | 权利人、授权用途、上传目标和真人本人配合无法由技术检查替代 |
| 结果保存位置 | 默认使用当前项目内独立运行目录 | 需要写入指定外部系统时 |

**默认激活模型：** Seedance 2.5、Seedance 2.0、Seedance 2.0 Fast、Seedream 5.0 Pro、Seedream 5.0 Lite、Seedream 4.5、Seed 2.1、Seedaudio 1.0。不要求客户填写或选择；安装与开通检查完成后，逐项告知已激活、已存在或受阻状态。显示名称由 Agent 映射为目标账户可用的准确 ID；同系列多个版本时优先复用可用版本，否则采用控制台当前推荐版本并记录。Seedance 2.5 为本指南视频验收的默认模型。资源包不被视为覆盖其他模型的通用额度。

推荐在早期完成企业 KYC。未完成所需认证会阻塞相关人脸素材库及后续授权流程；AI 生成的写实人脸也可能触发人脸审核，不能因为是 AI 生成就直接使用。平台另有受信任输出、预置角色等条件路径，应按具体素材规则检查，不能将企业 KYC 等同于肖像本人活体认证。[S17]

不要让用户把 API Key、AK/SK、证件或活体视频粘贴进聊天。

## 2. 执行地图与成功标准

下表是导航，详细动作、失败处理及证据要求见英文手册对应步骤。

| ID | 阶段 | 完成证据 | 后续路径 |
|---|---|---|---|
| MA-00 | 建立任务与预检 | 目标账户/区域/项目明确，固定模型清单与计费路径已记录 | MA-01；可并行准备 MA-07 |
| MA-01 | 账户与合同 | 账户可访问；所需商务/服务协议状态明确 | MA-02；高级分支进入 MA-03 |
| MA-02 | 模型激活与计费来源 | 目标模型显示可用；实际扣费来源、余额/额度可核对 | MA-06、MA-08 |
| MA-03 | 企业认证 / KYC | 控制台显示所需认证通过 | MA-04；不阻塞已具资格的基础生成 |
| MA-04 | 高级权益 | 实际权益档位、能力、额度及期限已核对 | MA-05、MA-09 |
| MA-05 | 真人资格与本人授权 | 真人资格可用、本人验证成功、对应素材组可查询 | 真人分支 MA-09 |
| MA-06 | 凭据与推理目标 | 凭据引用可用，目标模型/Endpoint、项目和权限匹配 | MA-08、MA-09 |
| MA-07 | 工具与连通性 | 本地依赖和版本明确，只读检查通过 | MA-08、MA-09 |
| MA-08 | 基础生成及 Playground 验证 | 基础 API 视频成功且可播放；Playground 能力单独记录 | MA-12；继续高级分支 |
| MA-09 | 素材组与上传 | 虚拟与真人素材分别进入正确素材组，保存返回 ID | MA-10 |
| MA-10 | 素材处理与审核 | 对应素材查询为 `Active` | MA-11 |
| MA-11 | 私有素材生成 | 虚拟与真人参考测试分别成功且结果可验证 | MA-12 |
| MA-12 | 交付与费用核对 | 能力验收矩阵、结果文件、任务记录、成本及待办齐全 | 全部通过才报告完成 |

### 必须保留的分支

- **已有账户/资源**：先验证当前状态。模型已激活、Endpoint 匹配、素材仍可用时复用，不按教程重新购买或创建。
- **新账户**：用户完成必要身份与条款步骤；Agent 准备并检查后续配置。
- **权益待商务开通**：记录 `WAITING_EXTERNAL` 和商务责任人，不把“购买一个付费档”当作自动替代。
- **真人能力受限**：记录具体缺失资格，暂停真人分支；可继续基础和符合条件的虚拟素材分支。
- **全部能力目标**：任何必需分支未通过即为部分完成。用户明确缩减范围后，才可重新定义完成条件。

## 3. 本版修正的关键产品规则

以下为 2026-10-21 的官方资料核验摘要，执行时仍须检查账户适用性。来源索引在 [核验记录](03-待确认与核验记录.md)。

1. **本客户流程固定使用 Seedance 2.5 资源包（USD）激活。** 这是用户指定的默认路径，不表示平台只支持这一条路径；已有资格与资源先验证复用，避免重复购买。Agent 准备当前有效订单，用户完成支付，不再询问激活方式。[S01–S03]
2. **激活资格与抵扣资格分别检查。** 能激活某模型不代表手上的资源包能抵扣该模型调用；未覆盖消耗可能走按量计费。[S03]
3. **高级权益包含免费 Entry 档。** 应先检查是否已授予、是否满足能力和容量，再决定是否需要付费；协议承诺开通不等于已生效。[S04]
4. **保留 Content filter 和素材默认审核。** 不把关闭过滤写成素材生成的前置条件；底线安全策略仍然存在。“Secure Mode”在原文中含义不清，未经核实不操作。[S05、S06]
5. **素材 `Active` 才能用于生成。** 上传成功返回 ID 不等于审核完成；不能承诺几秒内成功。[S06]
6. **企业认证与真人验证不同。** 企业认证不能替代肖像本人验证；两者分别验收。[S04、S08]

## 4. 用户只在明确的交接点参与

下表是本工作流的分工设计，不扩大工具或组织允许的权限。已有明确授权在同一范围内复用；动作对象、金额、权限或用途变化时重新核对。

| 步骤 | Agent 完成的准备 | 用户配合 | Agent 恢复条件 |
|---|---|---|---|
| MA-01 | 定位目标账户、邀请和待确认合同；整理对象与条款 | 登录验证、密码设置；接受合同或服务条款 | 会话可用、所需协议状态已生效 |
| MA-02 / MA-04 | 对比已有资格、拟购项目、最终价格、期限和退款条件 | 确认具体采购；本指南默认由用户完成支付 | 订单成功且额度/权益可查询；仅付款截图不足以判定开通 |
| MA-03 | 定位认证入口并说明所需材料类别 | 用户在官方页面提交企业/身份材料 | 认证状态通过；审核中则保留等待状态 |
| MA-05 | 确认目标主体、用途和认证入口 | 肖像本人完成授权及活体认证 | 可查询到验证结果和对应真人素材组 |
| MA-06 | 准备最小必要权限及凭据保存方式 | 批准新建或扩权；必要时在安全界面设置凭据 | 指定进程可用，日志不含秘密 |
| MA-09 | 检查素材、说明上传服务和用途 | 确认具体素材的上传及权利范围，已有充分授权则不重复询问 | 授权已记录且素材条件通过 |
| 安全配置例外 | 展示准确字段、理由、影响和官方依据 | 必须明确确认具体变更 | 变更后可验证；本流程没有默认需要关闭过滤的步骤 |

**交接消息模板：**

> 当前停在 `{step_id}`。我已完成 `{准备结果}`。请在 `{官方入口}` 完成 `{一个具体动作}`，涉及 `{账户/费用/数据/权限}`。完成后我会检查 `{成功证据}`，从 `{下一步骤}` 继续。等待期间可继续 `{独立任务}`。

Agent 不主动联系销售或第三方。需要外部联系时先准备消息草稿，按用户的明确发送授权处理。

## 5. 预算、工具和恢复原则

### 固定计费路径，减少提问

激活时准备 Seedance 2.5 资源包的 USD 订单，默认选择控制台当前满足激活条件的最低有效规格；最终金额、数量、有效期和退款条款在支付交接时展示，不预先增加预算问卷。后续使用按实际适用资源包抵扣与 pay-as-you-go 计费，不询问续费选择，也不自动订购付费高级权益。

测试默认每个验证场景一次，顺序执行基础 API、Playground、虚拟素材、真人素材；Agent 自行估算并记录费用，不询问客户测试预算、最多次数或是否允许按量计费。执行已授权的必要验证；具体工具若要求费用确认，在提交时展示准确操作和预计费用。删除问卷不等于授权无限调用。余额不足或价格异常时说明实际阻塞，不循环重试。

其他默认模型本轮验收其激活/可用状态，不自动为每个模型增加付费生成测试。需要额外测试时作为扩展任务处理。

### 不把安装 CLI 当作业务完成

本流程以官方 API/控制台为可用基线。`Volcengine CLI` 的安装不能证明它已正确连接 BytePlus。英文手册 MA-07 给出可选工具的安装与只读检查路径；确认兼容性前，不套用 `cn-beijing` 或其他平台凭据。实际调用必须验证目标账户、区域和项目。

### 可中断、可恢复

每次外部写入前记录计划，收到结果后立即记录资源/任务 ID。状态使用 `NOT_STARTED`、`READY`、`RUNNING`、`WAITING_USER`、`WAITING_EXTERNAL`、`BLOCKED`、`FAILED`、`VERIFIED`、`REUSED`。

超时不等于失败；提交结果不明不等于未提交。先按已保存 ID 查询，或核对服务端列表。无法确认时暂停该写入，不重复提交可能收费的任务。轮询到本地截止时间后保留任务，不自动取消或重建。具体轮询和退避策略见英文手册。

## 6. 最终交付与验收

Agent 在运行目录交付 `run-state.json`、`report.md` 和结果视频；本草稿中的名字仅是运行时约定，不代表已生成业务结果。

| 能力 | 验收要求 |
|---|---|
| 账户与模型 | 账户、区域、项目及计费来源明确；八个默认模型逐项有可用或受阻证据，不能以安装成功代替激活 |
| 基础 API | 请求返回任务 ID；最终成功；本地文件可解码和播放 |
| Playground | 同一目标模型可用；已授权的单次验证有结果证据 |
| 虚拟私有素材 | 合法素材、正确项目/组、`Active`、参考生成成功 |
| 真人能力 | 所需资格、本人授权、验证对应组、素材审核与参考生成全部通过 |
| 费用与恢复 | 区分估算、消耗与实际结算；记录等待项、责任人和恢复点 |

报告可写“基础 API 已验证，真人分支等待邀请资格”；不能写“全部开通完成”。结果中不包含密钥、证件、活体视频、认证会话 token 或带签名的私有下载链接。
