### 已采纳的执行默认值（v2）

- 激活路径固定为 Seedance 2.5 资源包，USD；已有资格先复用。需要购买时准备当前最低有效规格，客户核对具体订单并支付。
- 删除测试预算、最多次数、是否允许按量计费及续费的常规提问。后续采用适用抵扣和 pay-as-you-go；Agent 记录费用，必要的敏感交易交接仍保留。
- 默认激活八个指定模型，不让客户输入；安装和开通检查结束后逐项告知状态。其他模型不额外增加付费生成验收。
- 加强 KYC 建议及对后续人脸素材流程的影响提示。对“包括 AI 生成的”保留写实人脸审核提醒，但不写成无例外的产品禁令：官方存在受信任输出及预置角色路径。[S17]
- 企业 KYC 与肖像本人验证继续分开；纯虚拟角色不要求一个不存在的真人完成活体认证。

## 3. 已确认内容与冲突处理

“官方资料确认”表示检索到官方正文或官方索引正文支持该陈述，不等于目标账户已获权益，也不代表已做接口实测。部分官方页面直接打开只有标题；本次通过官方页面的搜索索引正文补充核验，未把标题当作规则证据。

| 主题 | 核验结论 | 草稿处理 |
|---|---|---|
| 唯一激活路径 | 官方资料已列出不止资源包一种路径 [S01、S02] | 区分平台支持多条路径与本客户默认选定资源包，两者不冲突 |
| 激活金额边界 | 激活页与 API 页对 Credits / 余额及 USD 30 门槛措辞不同 | 保留为平台资料差异；本流程已选资源包，不向客户提问该阈值 |
| 资源包 | 有效期、抵扣与超额计费规则需要分别理解 [S03] | 不把“激活所有系列”写成“跨型号通用抵扣” |
| 高级权益 | 官方表格包含免费 Entry 与付费档 [S04] | 替换“一律先购买”；实际授予和合同条件见 Q03 |

## 5. 文档验收与流程推演

以下是文档级检查，不是账户开通实测。程序静态检查的实际结果在完成检查后记录；流程推演检查各分支是否有明确动作、停止条件和恢复点。

| 场景 | 应有行为 | 文档覆盖 |
|---|---|---|
| 新账户 | 先确定账户，用户完成敏感注册/合同步骤，检查生效后继续 | MA-00/MA-01 |
| 现有账户与资源 | 按账户/区域/项目及当前状态复用，不重复购买或创建 | MA-00/MA-02/MA-06/MA-09 |
| 权益等商务开通 | 记录责任人与生效证据，不用付费采购代替协议授予 | MA-04、Q03 |
| KYC 未通过 | 只暂停依赖认证的分支，记录审核或驳回原因 | MA-03 |
| 真人资格缺失 | 单独等待，不把真人照片转为虚拟素材绕过 | MA-05/MA-09、Q04 |
| 费用与付款 | 不询问预算/次数；记录估算，余额不足或需付款时展示具体操作 | MA-02/MA-08、Q08 |
| 素材审核失败 | 保存 ID 与失败原因，不进入生成或重复上传相同内容 | MA-10 |
| 异步任务超时 | 本地停止轮询不等于服务端失败，保存任务继续查询 | 英文 §5 |
| 提交结果丢失 | 先查列表核对，无法判定则等待，不重复收费提交 | 英文 §5 |
| 项目不匹配 | 校验素材组、素材、Endpoint 和凭据项目；不重传到任意项目 | MA-06/MA-09/MA-11 |
| 权益过期 | 查询实际状态，不承诺已有素材永久可用，不自动续费 | MA-04/MA-11 |
| 视频状态成功但下载/解码失败 | 验收未通过，恢复同一结果下载，不立即再生成 | MA-08/MA-12、英文 §3/§5 |
| 仅基础能力成功 | 报告部分完成，其余能力保留阻塞证据和下一步 | MA-12 |
| 安全配置不明 | 保留配置，提出准确字段问题，不擅自关闭 | MA-06、Q05 |
