# 设置与客户交接

完整目标先读 [完整执行映射](full-onboarding.md) 及随包英文手册 MA-00–MA-07。下面是简要交接约定，不替代注册、合同、KYC 和高级能力步骤。

优先检查现有资源，不让客户回答本机可查的问题。账户/区域/项目有多个候选才让用户选择。默认八个模型清单在 SKILL.md；显示名不等于 API ID，Agent 查询当前目录并记录实际映射。Seedance 2.5 和 Seedream 4.5 可用即可推进默认创作；其他模型阻塞作为待办交付。

新账户需要用户本人登录，商务邀请和合同按实际账户处理。需要资金激活时使用已选 Seedance 2.5 资源包、USD：优先复用资格，否则准备当前满足激活条件的最低有效规格，展示最终商品、金额、数量、有效期和退款条件后交给用户支付。不推导 Seedance 资源包能够抵扣其他模型。

客户不填写测试预算、测试次数、pay-as-you-go 或续费问卷。Agent 估算必要调用费用并记录，按实际工具和授权要求确认具体提交，不将本 Skill 当作无限支付授权。高级权益付费订阅不是首次体验的默认购买项。

凭据：使用官方登录或安全的本地凭据机制。客户在官方页面/工具的安全输入界面完成；不要求复制到聊天、文档、截图或命令历史。只保存凭据引用和有效性检查结论。

敏感交接示例：

> 我已经准备好这一步。请在当前官方页面完成登录；完成后告诉我“好了”，我会检查并继续。

> 现在需要完成这笔资源包订单：{商品、数量、USD 金额、期限}。请核对订单并付款，完成后我会检查额度和模型状态。

> 你选择的真人参考流程需要先核对认证与授权。企业认证和肖像本人的验证是两步，我会带你到对应页面；证件和活体操作由你/本人直接完成。

每次交接都指出检查什么才继续，不只依赖用户口头“完成”。等待时继续独立准备，不反复催问。

setup 检查报告用本地 Markdown 保存：账户别名、区域/项目、工具和版本、八模型状态、首次创作所需凭据可用性（无值）、剩余待办。实际账号确认与工具只读成功后才能设置 setup done。仅版本命令或 ping 成功不足以证明模型权限。

KYC：推荐客户按业务需要尽早完成，尤其人脸/私有素材流程；不因默认产品演示强制收集证件。不把 AI 生成人脸自动当作自由使用素材，也不声称所有 AI 人脸均须真实人物活体验证。检查预置角色、受信任输出与客户素材各自适用条件。
